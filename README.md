🕒 Fuso Fácil - Conversor de Horário
Um conversor de fuso horário simples e visual, desenvolvido com HTML, CSS e JavaScript.

📌 Sobre o Projeto
Este projeto permite comparar o horário da sua cidade com o de qualquer outra cidade do mundo, em tempo real. Basta digitar os dois locais para ver os horários, saber se é dia ou noite em cada um, e copiar o horário com um toque.

🚀 Tecnologias Utilizadas

* 🏗 HTML → Estrutura da página
* 🎨 CSS → Estilização e responsividade
* 🎮 JavaScript → Lógica de fuso horário e interatividade

🎮 Como Usar?

1. Digite em qual cidade você está no campo "Você está nesse lugar? Alterar a localização".
2. Digite a cidade que deseja comparar no campo "Comparar com".
3. Os horários são atualizados automaticamente, a cada segundo, com a bandeira do país e o nome da cidade.
4. Toque em qualquer um dos horários para copiá-lo.

✨ Funcionalidades

* 🌍 Mais de 60 cidades cadastradas, com busca por autocompletar
* 🚩 Bandeiras reais de cada país (via biblioteca flag-icons)
* 📋 Copiar horário com um toque
* 🔴 Indicador de atualização em tempo real
* 📱 Layout responsivo
